# Скрипты для установки хаба

Здесь нет секретов. Ключи, пароль интерфейса и путь туннеля создаются на сервере
во время установки и никуда не отправляются.

- `survey.sh` — только читает. Ничего не ставит и не меняет.
- `install.sh` — ставит хаб. Не редактирует существующие файлы nginx, добавляет один
  новый. Проверяет, что сайт отвечает до и после одинаково, и откатывается, если нет.

Полное удаление: `sudo bash /opt/rendersys-hub/uninstall.sh --uninstall`
