# rendersys-beacon

Публичная точка восстановления связи для RenderSys.

В этом репозитории лежит один файл — `beacon.json`. Станция читает его **только** тогда,
когда все известные ей адреса перестали отвечать, и применяет содержимое **только** если
подпись совпадает с ключом владельца, зашитым в станцию при установке.

## Что здесь можно и нельзя

- Здесь **нет и не будет секретов**: только имена хостов и порты.
- Файл **подписан**. Кто угодно может его прочитать, но подделать — нет:
  приватный ключ никогда не покидает Mac владельца.
- Репозиторий публичный намеренно: станция забирает файл анонимно, без учётных данных.

## Как обновляют

На Mac владельца:

```
linkctl beacon-sign --endpoints-json '{"endpoints":[{"host":"новый.хост","port":443}],"reverseListenPort":22027}'
```

Получившийся `beacon.json` кладут сюда обычным коммитом. Станция подхватит его сама.
