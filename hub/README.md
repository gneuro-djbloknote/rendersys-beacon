# Скрипты хаба

`install.sh` **снят с публикации.** Он был написан под nginx на хосте и не подходит
для сервера, где nginx работает в Docker. Установка по нему привела бы к правке
конфигурации боевого сайта, которую следующий деплой всё равно перезапишет.

Новый установщик появится здесь после локального E2E в отдельной виртуальной машине.

`survey.sh` — только чтение, ничего не меняет. Им можно пользоваться.
